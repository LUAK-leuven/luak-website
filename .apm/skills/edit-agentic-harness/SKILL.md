This project uses apm (Agentic Project Manager) to manage and edit the agentic harness.

## Rules

- Always fetch the apm documentation (https://microsoft.github.io/apm/producer/author-primitives/) before making any changes.
- You should always edit the harness in the `.apm/` directory.
- **Do not edit the installed harness** (`.agents/`, `.opencode/skills`, ...)!
